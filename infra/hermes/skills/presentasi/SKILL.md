# Presentasi

1. Tujuan & audiens → pesan utama dalam 1 kalimat.
2. Alur: Masalah → Dampak → Solusi → Bukti → Rencana → Ajakan.
3. Satu pesan per slide (judul = kalimat kesimpulan), ≤ 5 poin, angka besar untuk data penting.
4. Buat dengan skill pptx-author (python-pptx) atau docx outline via create_document; sertakan catatan pembicara.
